# Architecture decision records

This directory holds the accepted architecture decisions for SolidInvoice. Each record
explains one decision, why it was taken, and what it rules out. It is engineering
material, not end-user documentation — the user manual lives in `docs/`.

Files are numbered in order of acceptance, and the number never changes. **An accepted
record is not edited.** If a decision changes, write a new record that supersedes the old
one, and add a `Superseded by` line to the old record. That is the only permitted edit to
an accepted record.
