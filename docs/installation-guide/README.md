# Installation Guide

SolidInvoice is an open-source application that allows you to manage clients and contacts and send invoices and quotes.

### System Requirements[¶](/broken/pages/1X9EDZ6TGRpsd1iCgh2J)

{% hint style="info" %}
In order to run SolidInvoice, you need at least PHP version **7.4.15**, but the latest version is always recommended
{% endhint %}

**Requirements:**

* PHP (>=8.2)
* A webserver
  * Nginx (Recommended)
  * Apache
* Any supported database
  * MySQL
  * PostgreSQL
  * MariaDB
  * SQLite (Embedded Database)
