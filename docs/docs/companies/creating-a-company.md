# Creating a company

## Creating a new company

To create a new company, select the existing company name from the top menu bar on the right. This opens a dropdown menu.

![Company dropdown menu](/img/docs/companies-dropdown.png)

Click the _+ Add Company_ link, which opens a page to create a new company.

![Create a new company form](/img/docs/companies-create-form.png)

Enter the name of your company (or whichever entity will be sending out invoices) and choose the currency. After entering the information, click the _Create_ button to create the new company with all the default configuration values set.

:::note
The name you choose for the company will be visible on all the quotes and invoices that are sent.
:::

After creating a new company, you'll be redirected to the dashboard of the new company.
