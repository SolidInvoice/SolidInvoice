# Creating a company

### Creating a new company

To create a new company, select the existing company name from the top menu bar on the right, which will then open a dropdown menu.

<figure><img src="../.gitbook/assets/Screenshot 2023-04-18 at 10.17.29.png" alt=""><figcaption><p>Creating a new company</p></figcaption></figure>

Click the `+ Add Company` link, which then opens a page to create a new company.

<figure><img src="../.gitbook/assets/screenshot (5).png" alt=""><figcaption><p>Create a new company</p></figcaption></figure>

Enter the name of your company, or whichever entity will be sending out invoices, and choose the currency for your company. After entering the information, clicking the `Create` button will create the new company, with all the default configuration values set.

{% hint style="info" %}
#### Note

The name that you choose for the company, will be visible on all the quotes and invoices that are sent
{% endhint %}

After creating a new company, you will be redirected to the dashboard of the new company.
